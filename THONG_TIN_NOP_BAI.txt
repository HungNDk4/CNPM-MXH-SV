HƯỚNG DẪN ĐÓNG GÓI TỆP NGUỒN ZIP (ĐẢM BẢO NHẸ VÀ CHUẨN ĐỂ NỘP)
================================================================================
Khi nén ZIP mã nguồn nộp cho Giảng viên, TUYỆT ĐỐI KHÔNG NÉN thư mục "node_modules" 
và ".git" (vì sẽ làm file nặng hàng trăm MB và dễ bị hệ thống nộp bài từ chối).

Cách đóng gói nhanh trên Windows:
1. Bạn có thể dùng WinRAR hoặc 7-Zip:
   - Chọn toàn bộ thư mục dự án "CNPM-MXH-SV" (trừ node_modules của client và server).
2. Hoặc chạy lệnh PowerShell tự động đóng gói sạch (khoảng 5-10 MB):
   powershell -Command "Compress-Archive -Path client, server, database, docs, scripts, package.json, README.md, PROJECT_CONTROL.md -DestinationPath CNPM_Nhom_OwlMate_SourceCode.zip"

Khi Thầy/Cô giải nén ra chấm bài, chỉ cần chạy:
- cd server && npm install && npm start
- cd client && npm install && npm run dev
Dự án sẽ khởi chạy ngay lập tức!
